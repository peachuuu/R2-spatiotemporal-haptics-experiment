# 游戏事件边界暂停与就地阈值校准设计

## 目标

在不改变现有事件、触觉样本、串口持有者或实验流程的前提下，让操作员可在游戏和样本评估期间安全暂停，并随时打开同一套阈值校准控件。

## 行为

- 游戏“暂停”是请求而非立刻中断：当前时间线事件及其音画触 cue 自然完成后，时间线进入 `awaiting-continue`，不启动下一事件。
- “继续”是唯一推进下一事件的操作。暂停边界内不改变角色物理、事件结果或已完成日志。
- 校准弹窗只渲染现有 `CalibrationGrid`，通过已有 R2 硬件连接适配器调用开始、停止、ARM 与 keep-alive；不创建 Web Serial 端口或第二硬件宿主。
- 打开校准弹窗先请求停止当前输出。校准时游戏保持暂停；关闭弹窗不自动继续。
- 样本评估页打开弹窗也先停止样本试听输出。

## 安全边界

- 仅硬件连接页是串口持有者；弹窗不得调用 `requestPort`、连接或断开。
- 不修改样本表、cue 调度、游戏时长、试次数、问卷与条件分配。
- 所有新状态仅为操作员 UI 状态，并写入既有运行日志的暂停/继续事件。
