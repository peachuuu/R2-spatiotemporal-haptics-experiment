# G07 可玩性参数说明

## 核心规则

- 飞行物：常速 5.0 s 穿越全屏，快速 3.0 s 穿越全屏。
- 危险区：事件开始时记录玩家横坐标，以该坐标为中心；记录后不再追踪玩家。
- 危险区先显示中心标记 0.6 s，再从中心向两侧扩张到半径 30% 的画面范围。
- 慢速扩张 2.6 s，边界速度约 `30 / 2.6 = 11.5%/s`。
- 快速扩张 1.9 s，边界速度约 `30 / 1.9 = 15.8%/s`。
- 玩家普通移动速度约 18%/s，因此两档都能在不使用冲刺的情况下跑出判定范围；快速档余量较小，用作较难样本。
- 视觉线宽、中心点、最终半径与碰撞判定共用同一组参数，命中只在扩张完成后的冲击时刻结算。

## 设计依据

- Riot 的技能清晰度原则强调：玩家需要能理解正在发生什么并作出响应；可躲避攻击应更醒目，视觉范围必须与命中范围一致。
- GDC Boss Up 强调围绕被测试的玩家技能设计攻击模式。本事件测试的是识别方向、移动逃离以及快慢差异，因此危险区锁定“生成瞬间的位置”，而不是持续追踪玩家。
- 响应性设计应给玩家提前看到未来事件的时间，不能依赖不可反应的瞬时命中。因此加入 0.6 s 中心预警，并使扩张边界速度低于普通移动速度。
