# 月萤遗迹：事件视觉素材制作指南

> **编号修订：当前系统使用 G01–G12。** 旧素材条目按以下映射迁移：旧 Boss 落地→G02，魔火→G03，幽灵→G04，左宝箱→G05，第一次凸棱→G06，局部视野战斗→G07，下雨→G08，右宝箱→G09，第二次凸棱→G10，全视野战斗→G11，Boss 倒地与烟花→G12。G01 方形机关保持不变。素材仍放入 `public/assets/events/<事件编号>/`。

## 0. 使用方式

本文件对应事件时间线 G01、G03–G18。素材制作时请保留以下原则：

- **角色控制权**：横版场景中，玩家角色的移动、跳跃、闪避和攻击由参与者控制；素材只表现环境、敌人与反馈，不能把角色做进不可控的剧情视频。
- **素材优先级**：先做“可跑通版”关键图，再补充序列帧与细节特效。没有最终图时系统会显示占位图。
- **文件格式**：背景为 PNG/JPG；角色、特效、道具和 UI 使用透明 PNG；建议 RGB/sRGB。像素风素材不要开启平滑缩放。
- **目录规则**：`public/assets/events/G03/` 这类目录；一个事件的素材只放自己的编号目录。
- **避免生成文字**：AI 图中不要包含可读文字、数值、logo、界面按钮或水印；文字由代码叠加。

## 1. 整体视觉风格

### 视觉关键词

暗色横版像素遗迹、被遗忘的月光神殿、冷蓝紫夜色、石质地面、荧光青蓝、稀疏暖橙火焰、低饱和、克制神秘、16-bit RPG、清晰轮廓、横向动作游戏、可读性优先。

### 色彩与镜头

| 用途 | 色彩/处理 |
|---|---|
| 常态遗迹 | 深靛蓝、蓝灰石材、暗紫阴影、少量青色荧光 |
| 危险与 Boss | 暗红、紫红、橙红火焰；不能大面积遮挡角色 |
| 局部可见 | 保持场景存在，仅用代码雾层遮蔽；背景图不必专门做黑图 |
| 下雨后 | 保留原遗迹结构，增强湿润高光、青蓝反射和远景可见度 |
| 特写交互 | 深色石材或金属器物居中，背景简化，手指轨迹和发光边缘清晰 |

### 全局 Lovart 基础提示词

```text
dark side-scrolling pixel-art moonlit ruins, ancient stone sanctuary, deep indigo and blue-gray palette, sparse cyan magical glow, restrained warm orange accents, mysterious but readable 16-bit action RPG environment, crisp pixel clusters, clean silhouette separation, atmospheric depth, no text, no logo, no UI, no watermark
```

每个事件提示词都在此基础上补充。若 Lovart 支持负面提示词，统一使用：

```text
no text, no letters, no numbers, no logo, no watermark, no photorealism, no anime line art, no glossy 3D render, no blurry pixels, no interface, no character close-up unless requested
```

## 4. 推荐制作顺序

1. **第一批：** G01 机关、G07 宝箱特写、G03 Boss、G05 幽灵、通用宝箱、投射物、危险符文。它们足以跑通全部事件。
2. **第二批：** G04 魔火、G11 雨、G16 击败、G17 烟花。
3. **第三批：** 各事件序列帧、潮湿反射层、G13 和 G14/G15 的细微变体。

## 5. 给 Lovart 的交付提醒

- 单个角色、道具和特效要求“transparent background / isolated game asset”。
- 横版背景要求“no character, no UI”；不要让 AI 生成不可替换的主角。
- 先保留原尺寸 PNG；抠图后也保留一份源文件。
- 生成序列帧时保持画布、锚点、像素比例一致，避免角色或特效在播放时抖动。
